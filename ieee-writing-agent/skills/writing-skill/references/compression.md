# Compression

Shorten the authorized text to the requested target while preserving its claim, evidence and technical meaning. Existing text supplies the claim for a meaning-preserving edit; no separate claim field is required. Process a multi-paragraph scope sequentially and check its final flow.

Protect relevant numbers, conditions, baselines, uncertainty, negative findings, source attributions, labels and LaTeX. A pasted result can be edited without its raw data, but do not claim to have verified the number. If the target cannot be met without losing material content, deliver the shortest faithful version and explain the tradeoff.

Useful operations, chosen as needed: remove repeated motivation and empty openings; merge compatible sentences; replace vague evaluation with already supplied specifics; shorten tutorial material while retaining necessary references; interpret rather than repeat a table; reduce redundant transitions. Do not add a new takeaway unsupported by the original merely to improve flow.

Run the prose gate on changed text and terminology checks when technical forms change. Keep necessary disclosure wherever readers need it; a standalone abstract and body may both need the same condition. Return the compressed text and a brief material-change/word-count note when useful, without a mandatory multi-table report.
