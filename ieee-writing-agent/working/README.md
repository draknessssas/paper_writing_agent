# Working Files

This folder stores current-manuscript analysis for the TPEL writing workflow. These files are not style memory.

Recommended Markdown files:

```text
working/current_manuscript_brief.md
working/evidence_packet.md
working/intro_reference_map.md
working/claim_ledger.md
working/citation_audit.md
working/section_plan.md
working/figure_caption_plan.md
working/submission_audit.md
working/response_plan.md
working/compression_notes.md
working/reviewer_comments.md
```

Use these templates:

```text
templates/md-inputs/current-manuscript-brief.md
templates/md-inputs/evidence-packet.md
templates/md-inputs/reviewer-comments.md
```

Current experimental results, prototype ratings and operating conditions, model-validation datasets and error metrics, waveform and figure descriptions, table values, reviewer comments, and allowed/forbidden claims belong here or in the live conversation, not in `corpora/my_papers` or `corpora/domain_papers`.
