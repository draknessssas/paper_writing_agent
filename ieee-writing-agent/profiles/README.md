# Profiles

Start from [index.md](index.md) to select relevant sections. Full language/argument profiles and per-paper skeletons are retained as source-derived preferences, not mandatory prose recipes or evidence for the current study.

Active paths are in `active_profile.yml`. An empty author_style means no author-specific profile is selected; create one with `style-profiler <folder> author` when you want it. The pre-2026-09 TPEL-era profiles were removed on 2026-09-14 (unused by these skills; recoverable from git history).

Use style-profiler when the user requests extraction or refresh. Creating a new manuscript, adding a citation or missing an optional profile does not itself authorize corpus processing. Record source identities, dates, coverage and extraction limits when refreshing a profile.
